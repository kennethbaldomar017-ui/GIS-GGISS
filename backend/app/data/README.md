# Cabadbaran indicative boundaries

`cabadbaran-boundaries.geojson` contains the 31 features whose ADM3_PCODE is
`PH1600203`, extracted from:

https://github.com/bendlikeabamboo/barangay-boundaries-repository/releases/download/v2026.4.13.0/barangays.geojson

Credit: NAMRIA administrative boundaries, version 2023-11-06; PSA PSGC snapshot
2023-10-24; conversion/enrichment by bendlikeabamboo/barangay-boundaries-repository.
Retrieved 2026-10-28. Names have only had the ` (Pob.)` suffix removed.

The source uses 0.005-degree geometry simplification. These polygons are indicative
display outlines, not surveyed or legal boundaries. They may differ from a newer
basemap or local cadastral data. Dot locations are illustrative; density is a
display setting and does not add measured cases.

The GeoRisk PSA query service timed out. A separate GEODATA atlas service was
evaluated but rejected because its Tolosa polygon did not align with the basemap's
Tolosa location. Its geometry is not used.
